# STOPWATCH

A stopwatch with lap times. There is no clock, so it counts frames (1 frame = 1 centisecond); the time is approximate. The best lap is saved to /home/ai/stopwatch/best.txt.

## Controls

- SPACE: start or stop the timer
- l or ENTER: record a lap while running
- r: reset time and laps (only when stopped)
- h: open lap history
- j/k or DOWN/UP: scroll lap history
- s: save best lap time
- ESC: back from history; quits on the main screen
- q: quit
