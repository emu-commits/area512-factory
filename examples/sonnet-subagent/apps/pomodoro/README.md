# POMODORO

A 25-minute focus / 5-minute break timer that counts completed focus sessions and saves the count to /home/ai/pomodoro/count.txt.

Time is approximate (frame-polled, no clock) and the count is a total across runs.

## Controls

- SPACE: start or pause the countdown
- n: skip to the next phase (skipping a focus phase does not count a session)
- r: reset the current phase to full length and pause
- c: clear the session count (asks to confirm)
- q / ESC: quit
