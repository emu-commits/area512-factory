# UNIT CONVERTER

Convert a typed number between units of length, weight and temperature.

Categories and units:
- LENGTH: mm, cm, m, km, in, ft, yd, mi
- WEIGHT: mg, g, kg, oz, lb
- TEMP: C, F, K

Controls:
- 0-9: append a digit (max 10 chars)
- . : decimal point (only one)
- - : toggle a leading minus sign
- BS: delete last character
- c: clear the value
- LEFT/RIGHT (h/l): switch category
- UP/DOWN (k/j): change the from-unit
- s: cycle the to-unit
- x: swap from-unit and to-unit
- ENTER: save category, units and value as the default
- q or ESC: quit
