# TODO

A checklist where you add, check off and delete items, saved to the SD card.

Data: /home/ai/todo/items.txt (up to 100 items, 40 chars each).

## Controls

- UP / k: move cursor up
- DOWN / j: move cursor down
- a: add an item
- SPACE or ENTER: toggle done / not done
- d or BS: delete the item (confirm)
- c: clear all done items (confirm)
- ESC or q: quit
