# DICE ROLLER

Pick a die type (d4 to d20) and a count, roll them, and see each die plus the total.

## Controls

- LEFT / h: previous die type
- RIGHT / l: next die type
- UP / k: more dice (max 10)
- DOWN / j: fewer dice (min 1)
- 1-9: set the dice count directly; 0 sets it to 10
- ENTER / SPACE / r: roll the chosen dice
- i or H: open or close the history screen (last 8 rolls)
- s: save the current die type and count
- ESC: close history; on the main screen quit
- q: quit (saves die type and count)
