# 2048

Classic 2048 sliding-tile puzzle on a 4x4 grid. Merge equal tiles to reach 2048. The best score is saved to /home/ai/game2048/best.txt.

## Controls

- Arrows or h/j/k/l: slide all tiles left/down/up/right
- n: new game (asks to confirm if the score is above 0)
- q or ESC: quit (saves the best score)
