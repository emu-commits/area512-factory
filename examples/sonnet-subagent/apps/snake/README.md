# SNAKE

Classic real-time snake game: steer a growing snake to eat food on a 20x10 grid without hitting the walls or yourself. Best score is saved to /home/ai/snake/best.txt.

## Controls

- UP / k / w: turn up
- DOWN / j / s: turn down
- LEFT / h / a: turn left
- RIGHT / l / d: turn right
- ENTER: start from Ready, restart from Game over
- p: pause / resume
- ESC: quit from Ready or Game over; pauses during play
- q: quit
