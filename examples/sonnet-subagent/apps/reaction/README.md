# REACTION TEST

Measure how fast you press a key after the screen turns green, over 5 rounds, and keep your best average. Timing is frame based (1 frame = 30 ms), so there is 30 ms resolution.

## Controls

- SPACE / ENTER: start a round, react when the screen is green, advance past results, restart after the summary
- Pressing during WAIT counts as too early; the round repeats without counting
- q: quit
- ESC: quit

Best average is saved to /home/ai/reaction/best.txt.
